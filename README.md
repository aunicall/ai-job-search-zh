**Offer来敲门**是一款覆盖求职全流程的开源 AI 助手，帮助您发现合适的机会、呈现真实的职业优势，并为每一次面试做好准备。从职位筛选、简历定制到投递跟进与面试复盘，让每一步求职都有据可依。

## 核心功能

- **职位发现**：聚合多个招聘来源，按个人档案或自定义条件搜索并分析匹配度；每个平台默认最多读取 50 条，可在设置中调整。
- **简历定制**：导入现有简历，生成岗位专属简历与沟通话术；支持六种模板及 Word、PDF、Markdown 导出。
- **投递管理**：跟踪求职进度，保存职位与投递材料快照。
- **面试练习**：生成准备包、题目与参考答案，支持文字和语音模拟面试、3D 面试官及逐题反馈。
- **持续复盘**：管理面试记录与求职笔记，积累可回顾的练习成果。

## 快速开始

### 环境要求

- **Node.js：推荐 24+，最低 22.13.0（尚未验证）。** 需安装 npm。
- 至少一个已安装、登录且有可用额度的 **Codex、CodeBuddy 或 Claude Code CLI**，参见[引擎配置](docs/ai-engines.md)。
- **Edge 或 Chrome**，用于获取部分招聘平台的职位信息和导出 PDF。


### 本地运行

```bash
git clone https://github.com/aunicall/ai-job-search-zh.git
cd ai-job-search-zh
npm ci
npm run dev
```

访问 [http://127.0.0.1:3001](http://127.0.0.1:3001)，在「引擎与设置」检查连接，然后完善个人档案。

本项目面向单机使用，招聘浏览器需要可交互的桌面环境。无桌面的服务器或容器不能直接使用需要人工登录、验证的招聘平台。

构建后运行：

```bash
npm run build
npm start
```

应用默认仅监听 `127.0.0.1`，需要本机 CLI 和可写磁盘，不支持静态部署。当前无账号鉴权，请勿直接开放到公网。

> 测试备注：Codex（`0.142.5`）和 CodeBuddy（`2.172.1`）已完成真实账号全流程测试。Claude Code 已实现接入和 Skill 安装适配，但因没有账号，未做测试。有 Claude Code 账号的小伙伴如果感兴趣，欢迎帮忙测试流程，非常感谢！这不代表所有招聘平台与账号都已逐一验证。

## 配置

将 [.env.example](.env.example) 复制为同目录下的 `.env.local`，按需取消注释并填写值；已有文件请直接编辑。所有配置均为可选，修改后重启服务。

| 变量 | 用途 | 默认值 |
| --- | --- | --- |
| `PORT` | 启动端口 | `3001` |
| `OFFER_DATA_DIR` | 数据目录，建议使用仓库外的绝对路径 | `./data` |
| `OFFER_AI_TIMEOUT_MS` | AI 生成超时，单位毫秒 | `180000` |
| `OFFER_BROWSER_CHANNEL` | 浏览器：`msedge` 或 `chrome` | Windows 为 Edge，其他系统为 Chrome |
| `OFFER_CAMPUS_API_KEY` | Offer先生校招接口密钥 | 未配置时该来源不可用 |

例如，设置 `PORT=3002` 后访问 `http://127.0.0.1:3002`。开发和构建后运行均支持，也可用 `--port` 临时覆盖。AI 登录由 CLI 管理，命令和模型在应用内配置。

## 招聘来源

| 来源 | 接入方式与使用条件 |
| --- | --- |
| 猎聘 | 公开接口按页码取数，并读取职位详情；接口受限时尝试浏览器，部分详情可能需要登录或验证。 |
| BOSS直聘 | 本地浏览器读取职位，需自行登录并设置平台求职期望；支持页面翻页或滚动加载，可能受验证和访问频率限制。 |
| 智联招聘 | 本地浏览器读取职位，需自行登录；支持页面翻页或加载更多，详情以当前账号可见内容为准。 |
| 前程无忧 | 本地浏览器读取职位，支持页面翻页或加载更多；需要登录或验证时由用户完成。 |
| Offer先生 | 三个引擎均通过官方 `offer-skill` 查询校招公告，按游标翻页；需[申请接口密钥](https://developer.offerxiansheng.com/docs/ai)。Skill 缺失时从官方安装到用户目录，不随本项目分发。 |

在「引擎与设置」可调整每个平台的原始搜索结果上限，默认 **50 条**，可设为 1–500 条；同一轮中多个关键词共用平台额度。达到上限或没有新结果时停止，最终展示数量可能因去重、筛选而减少。网页翻页适配尚未逐个平台完成登录后的实测。

来源可用性受平台页面、账号权限和访问限制影响。项目不绕过验证码、不自动投递；也支持手动添加职位。

## 数据与隐私

### 隐私保护

- **身份信息留在本地**：个人档案中的姓名、电话、邮箱不会主动发送给 AI；生成简历时由代码拼入，头像也在本地处理。
- **AI 处理求职内容**：发送前脱敏已知身份信息，将经历、技能、职位描述、相关笔记、面试题与作答等任务上下文交给所选 CLI。Codex、CodeBuddy、Claude Code 分别通过其配置的 OpenAI、腾讯或 Anthropic 服务处理；若 CLI 配置了第三方模型或网关，内容会发送至该服务。自由文本仍需自行检查。
- **招聘与语音服务**：搜索词、城市等条件发送给所选招聘平台；Offer先生查询仅发送接口支持的搜索条件，不发送整份简历。Windows 本机语音能力在本地处理，浏览器语音识别或合成可能将音频或文字发送给浏览器、系统配置的语音服务商。

### 数据存储

档案、求职记录和附件默认保存在本机 `data/` 目录，可通过 `OFFER_DATA_DIR` 修改。请勿将个人数据或 `.env.local` 提交到仓库。

| 内容 | 默认位置 |
| --- | --- |
| 档案、职位、设置、面试题与作答等结构化数据 | `data/offer.sqlite`（SQLite，运行时还可能有 `-wal`、`-shm` 文件） |
| 导入文件、生成材料、头像等文件 | `data/workspace/`；可在应用设置中单独修改文件目录 |
| 招聘浏览器的 Cookie 和登录状态 | `data/source-browser/` |
| AI 登录凭据与官方 Skill | 由各 CLI 保存在当前系统用户目录，详见[引擎配置](docs/ai-engines.md) |

备份前先停止服务，复制整个数据目录；另设的文件工作目录也需一起备份。设置页 JSON 导出不包含附件，当前没有网页端导入恢复功能。完整步骤见[使用指南](docs/usage.md#数据备份与迁移)。
