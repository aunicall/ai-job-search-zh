# 使用帮助

[返回项目首页](../README.md) · [AI 引擎安装与配置](ai-engines.md)

建议按「个人档案 → 发现职位 → 投递材料 → 面试准备 → 模拟面试 → 复盘」使用。首次使用时没有演示数据，先连接 AI 引擎并填写档案。

## 1. 连接 AI 引擎

打开「引擎与设置 → AI 引擎」，选择已安装并登录的引擎，保存配置并检查连接。连接测试会发起真实模型请求，可能消耗额度。命令能输出版本号只代表安装成功，不代表账号和模型可以使用。

设置页分为「AI 引擎」「数据与工作空间」「任务日志」三个标签页。标签之间切换会保留未保存的修改；离开设置页时会提醒保存。仅修改搜索结果上限并保存，不会触发引擎检测。「任务日志」按时间汇总 AI 任务与职位发现记录，显示任务状态、执行结果和完整时间。点击职位发现的「查看详情」，可查看该次搜索条件、各平台结果与运行日志，运行中的记录会自动刷新。

## 2. 建立个人档案

在「个人档案」中填写目标岗位、城市、经历、技能、薪资期望与排除条件，也可导入 PDF、DOCX、TXT 或 Markdown 简历辅助提取。AI 提取结果需您确认后保存，不会自动覆盖已有档案。

姓名、电话、邮箱由本地保存与处理，本项目不会主动发送这些档案字段给 AI 引擎。导入时先在本地提取身份信息并脱敏，再将经历文本交给 AI；无法识别的姓名请在档案中手动补全。提取前请检查文本中的其他姓名、证件号、详细住址等，自动脱敏不能保证识别所有自由文本隐私。

扫描版 PDF 请先做文字识别，旧版 DOC 请先转换为 DOCX。头像为选填项；未上传时，正式简历不显示照片区域。模板页的姓名与照片框只是示例。

尽量写清个人职责和真实成果，避免只有项目名称。生成内容应由您核对，不能把 AI 推断当作个人经历。

## 3. 发现并管理职位

在「发现职位」选择「根据个人档案」或「自定义条件」。档案模式使用已保存的求职方向、城市、技能与经历；自定义模式可填写目标方向、城市、期望薪资、工作经验、学历、技能、其他偏好和排除条件，不修改或套用个人档案，除目标方向外均可留空。自定义结果的评分表示与本次条件的符合程度。

档案模式展示已保存的信息摘要；如需修改，点击页面右上角的「个人档案」或侧边栏同名入口。自定义条件中，红色星号表示必填项。

选择招聘来源后，点击「开始发现」。需要登录的平台，先点击对应的「打开 / 登录」，在本地浏览器完成登录与必要验证。

结果展示匹配依据、待确认事项和来源链接。将感兴趣的职位加入候选后，可在「职位管理」查看完整描述、匹配分析、投递材料、面试准备和跟进记录。也可以直接手动添加职位。

来源遇到验证、限流或页面读取失败时，查看任务日志处理；不要反复点击开始。平台支持详情见 [项目首页](../README.md#招聘来源)。

在「引擎与设置 → 数据与工作空间」中可调整「每个平台的搜索结果上限」，默认 50 条，支持 1–500 条。每轮搜索中，同一平台的多个关键词共用这个额度，先取原始结果，再去重和匹配筛选；最终机会数可能小于上限。修改设置对下一轮搜索生效。

Offer先生按游标、猎聘按页码读取；BOSS直聘、智联招聘和前程无忧使用网页的下一页、加载更多或滚动加载。达到上限或没有新结果时停止；遇到登录、验证、限流或翻页失败时保留已有结果，并在来源状态中提示。数量越多，读取详情和 AI 筛选越慢，请耐心等待，或随时取消。

获取结束后，AI 会对已取得且描述足够完整的职位分批评分，不再继续获取新职位。CodeBuddy 每批最多 5 条，其他引擎每批最多 20 条；批次数不代表搜索翻页次数。

如果评分调用失败或只返回部分职位的评分，任务会标为未完成，并显示已评分、未评分和保留的职位数量；未评分职位仍可查看。服务重启后，未结束的职位发现会标为中断，已获取结果保留，直接打开任务日志也能看到恢复后的状态。

## 4. 生成简历与沟通话术

在职位的「投递材料」中选择简历模板，或交给 AI 自动选择，然后生成投递简历。流程会结合档案与职位进行起草、审阅和修订，同时生成沟通话术。

AI 只生成并审阅简历正文，姓名、电话、邮箱由本地代码在审阅完成后拼入，头像也在本地排版。后续面试或能力分析会移除简历身份头，并在发送前对已知身份信息脱敏。导出文件和已投递快照保留生成时的个人信息，请妥善保存。

「生成记录」按时间从新到旧排列，一行对应一次生成，可分别查看简历与话术。简历支持 Word、PDF、Markdown 导出，PDF 需要本机 Edge 或 Chrome。

请核对姓名、联系方式、经历、成果和岗位相关表述，再到招聘平台自行投递。完成实际投递后，点击「标记已投递」；应用会保留当时的职位与材料快照，供后续面试准备使用。

## 5. 准备面试

在「面试准备」先打开配置，填写面试类型、形式、面试官、本轮补充信息和公司背景。关闭配置窗口时自动保存；保存失败会提示，不会悄悄丢弃修改。

题目数量不填时由 AI 自动决定，也可以设置 1～30 道题。公司资料可以填写您确认的信息及资料来源；准备包不会把您提供的资料表述为已完成联网核实。

生成准备包后，在「生成记录」查看结果。准备包用于梳理面试重点；模拟面试的整套题目需在「模拟面试」页面单独生成。

## 6. 进行模拟面试

1. 在「模拟面试」选择候选职位，检查「面试配置」，点击「生成面试题」。
2. 等待题目就绪。每次生成是一份固定题组，在表格中占一行。面试题与参考答案生成后不可编辑，重新生成会新增题组，不覆盖原题。
3. 点击该行「模拟面试」列中的「开始」，打开面试窗口。首次作答可选择文字或语音模式、确认难度，再点击「开始面试」。开始前调整难度会使原题不再匹配当前配置，需要重新生成。
4. 阅读题目并作答，确认后点击「提交回答」。回答保存成功后立即进入下一题，AI 点评在后台进行，无需等待点评完成。

出题时，全局「AI 设定」是最高优先级的用户指导，以当前个人档案和职位要求为核心，再综合相关面试反馈、求职笔记及历史多次作答，调整考察重点与难度。历史回答和 AI 反馈只作为练习参考，不会被当成真实履历。修改档案或设定只影响新生成的题组，不改动已有面试题。

生成整套题目和参考答案需要处理较多信息，可能耗时较长，请耐心等待。题目就绪前不能开始面试；逐题提交只调用 AI 点评回答，不会重新生成下一题。

### 题组与多次作答

同一题组可以多次作答，面试窗口标题右侧显示「第 N 次作答」。题组表格中的「面试题」与「作答记录」分别提供「查看」入口：前者只展示固定题目、参考答案和出题依据，后者展示每次练习的记录。

- **重新开始**：确认后保留本次已提交的作答与反馈，新增一次作答，复用已有题目从第一题开始；当前未提交的文字或录音会被清空。后台点评不阻止重新开始，旧点评仍归入原来的作答记录。
- **关闭面试窗口**：点击右上角关闭按钮。已提交的回答会保留，之后可从同一题组继续；关闭窗口不会停止后台点评。未提交内容不作为作答记录保存，正在录音或识别时关闭会提示确认放弃。
- **删除题组**：点击题组表格「操作」列的删除按钮。确认后删除本题组的题目、参考答案、全部作答记录、点评日志与反馈，以及应用保存的关联文件。已下载到其他位置的副本不会被删除。

### 查看作答记录与点评日志

从题组表格或面试窗口点击「作答记录」，打开记录表格。一行对应一次作答，展示次数、开始时间、答题进度、作答状态、AI 点评状态及可用操作。作答是否结束与点评是否完成是两种独立状态，答完最后一题后，点评仍可能在后台处理。

点击某行「查看」，打开标题为「第 N 次作答」的独立弹窗，阅读该次的题目、回答和反馈。反馈按「亮点」「改进建议」「与参考答案的差异」分段显示。关闭详情后，作答记录表格仍保留；关闭记录表格不会同时关闭原来的模拟面试窗口。

「AI 点评」列显示点评状态和已完成数量；点击「查看日志」，可查看该次作答的排队、调用 AI、停止、恢复、完成或失败记录及时间。旧记录可能没有详细日志。作答记录、作答详情和日志弹窗与模拟面试窗口大小一致，表格与内容区域可独立滚动。

### 停止与恢复 AI 点评

点评控制位于「作答记录」表格的「点评控制」列，不在作答界面中。每次作答独立控制，不影响其他轮次。

| 点评情况 | 显示状态 | 可用控制 |
| --- | --- | --- |
| 尚未提交回答 | 待作答 | 无 |
| 有正在处理或排队的点评 | 点评中 | 停止点评 |
| 已暂停，且还有待点评回答 | 已暂停 | 恢复点评 |
| 所有已提交回答均已点评 | 已完成 | 无 |
| 点评全部失败或部分失败，且没有待处理任务 | 点评失败 / 部分点评失败 | 无 |
| 旧回答没有点评结果或任务状态 | 暂无点评 | 无 |

点击「停止点评」会取消该次作答正在调用的 AI 点评，并暂停排队任务。您仍可继续回答和提交，已完成的点评保留；点击「恢复点评」后，继续处理尚未完成的点评。点评暂停、失败或耗时较长，都不影响已保存的回答。

后台点评需要应用服务保持运行。关闭运行服务的终端或重启服务会中断任务；重新打开后，可在点评状态和日志中查看中断情况。恢复点评用于继续已暂停的任务，不会自动重试已失败或因服务重启而中断的任务。

### 语音模式

首次使用需确认语音说明并授权麦克风。录音结束后，先核对识别文字，再提交；专有名词可能识别错误。单次录音最多两分钟，可追加录音或改用键盘。

Windows 优先使用已安装的中文语音能力，其他环境可能使用浏览器语音服务。没有中文声音或识别能力时，可安装系统中文语音组件，或直接使用文字模式。联网识别或合成的数据流向见 [项目首页](../README.md#数据与隐私)。

## 7. 管理真实面试与复盘

实际投递后，在「面试管理」记录邀请、轮次、时间、形式、地点、联系人和反馈。模拟面试记录与真实面试记录独立保存。

「求职笔记」适合记录表达问题、经验和复盘。笔记卡片显示完整更新时间，点击删除按钮并确认后可删除笔记。

「AI 设定」用于补充您希望所有 AI 任务遵循的风格与要求。后续准备会结合相关笔记和实际面试反馈，但不会把这些内容自动写入履历。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 生成简历或面试题很慢 | 引擎需要处理大量上下文，简历还可能经过多轮审阅。请耐心等待并查看任务进度，可切换页面；不要关闭运行服务的终端。 |
| 回答已提交，但点评尚未完成 | 可以继续回答下一题；在「作答记录」查看 AI 点评状态与日志，检查是否已暂停。 |
| 任务失败或超时 | 查看错误信息，先确认 CLI 账号、模型、额度与网络可用。确认不是连接问题后，可按引擎文档适当增加超时时间。 |
| 搜索不到职位 | 检查来源是否登录、关键词和城市是否过窄，以及是否被全职/实习等条件排除；查看来源日志，也可手动添加职位。 |
| 导出 PDF 失败 | 确认已安装 Edge/Chrome，必要时配置 `OFFER_BROWSER_CHANNEL` 并重启服务。 |
| 更换数据目录后记录不见了 | 切换路径不会搬迁旧数据库。停止服务后迁移旧数据，或恢复原路径；不要直接删除原目录。 |

## 数据备份与迁移

默认数据位于项目的 `data/` 目录；设置 `OFFER_DATA_DIR` 后，以该目录为准。

| 内容 | 位置 |
| --- | --- |
| 档案、求职记录与配置 | `offer.sqlite` |
| 导入文件、生成材料与头像 | `workspace/` |
| 招聘平台登录会话 | `source-browser/` |

在「引擎与设置 → 数据与工作空间」中，手动修改「文件工作目录」后，移出输入框焦点即自动保存；Windows 用户也可点击「浏览本地文件夹」，在系统窗口选定目录后自动保存。取消选择不会更改已保存的目录。其他系统可手动填写绝对路径。目录旁的提示按钮可查看存储说明。

备份或迁移前，先停止服务，再复制整个数据目录。若在应用中单独设置了文件工作目录，也需一并复制。更改目录配置不会自动搬迁已有数据。

设置页导出的 JSON 备份不包含附件，当前不支持网页端导入恢复。CLI 登录凭据由各 CLI 管理，不随项目数据迁移。
